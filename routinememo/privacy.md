「루틴메모」(이하 「앱」)는 사소 스튜디오(Saso Studio)가 운영하는 운동 기록 앱. 이 방침은 앱이 다루는 개인정보의 항목·목적·보관·삭제 방법 안내.

## 1. 수집 항목

| 구분 | 항목 | 수집 방법 |
|---|---|---|
| 계정 정보 | Google 계정 이메일 주소·이름, Firebase 사용자 식별자(UID) | Google 로그인 시 자동 |
| 운동 기록 | 직접 입력한 루틴·종목·세트(무게·횟수·시간)·메모·운동 날짜와 소요 시간 | 이용자 직접 입력 |
| 앱 이용 정보 | 앱 실행·화면 이용 통계, 기기 모델·OS 버전, 앱 인스턴스 식별자 | Google Firebase 애널리틱스 자동 수집 |

위치 정보·연락처·사진·건강 센서 데이터는 수집 대상 제외.

## 2. 이용 목적

- 로그인과 기기 간 기록 동기화
- 루틴·운동 기록의 저장과 표시, 공유용 텍스트 생성
- 앱 오류 파악과 기능 개선을 위한 이용 통계

광고·마케팅 목적의 이용과 판매는 미실시. 앱 안 광고 미포함.

## 3. 보관 위치와 처리 위탁

- 저장소: Google Firebase(Firestore · 서울 리전 asia-northeast3)
- 처리 위탁: Google LLC — 로그인(Firebase Authentication), 데이터 저장(Cloud Firestore), 이용 통계(Firebase 애널리틱스)
- Google의 처리 과정에서 국외(미국 등) 서버 이용 가능성 존재. 상세는 [Google 개인정보처리방침](https://policies.google.com/privacy) 참고

## 4. 보유 기간과 파기

- 보유 기간: 계정 삭제 시까지
- 계정 삭제 시: 루틴·운동 기록·종목·순환 순서 등 이용자의 서버 데이터 전부와 로그인 계정 즉시 삭제
- 이용 통계는 Firebase 애널리틱스 보존 기간 설정에 따라 자동 파기

## 5. 계정과 데이터 삭제

- 앱 안: 홈 오른쪽 위 계정 아이콘 → 「계정 삭제」 → 본인 확인을 위한 Google 계정 재선택 → 삭제 완료
- 앱 없이 요청: [계정 삭제 요청 안내](/routinememo/delete-account/) 참고

## 6. 제3자 제공

이용자의 개인정보를 제3자에게 미제공. 공유용 텍스트는 이용자가 직접 복사·전송하는 경우에만 외부 전달.

## 7. 이용자의 권리

언제든 열람·정정·삭제 요청 가능. 운동 기록은 앱에서 직접 수정·삭제 가능, 그 밖의 요청은 아래 연락처로 접수.
